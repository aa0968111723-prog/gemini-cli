# 學習文件中心

歡迎來到學習文件中心，這裡彙整了課程內容、學習影片與測驗資源，幫助你循序完成學習。

本中心的目標是提供一條「可落地、可追蹤、可驗證」的學習路徑：

- **可落地：** 每個單元都有明確的輸入（先備知識）與輸出（你要完成的成果）。
- **可追蹤：** 你可以用固定節奏（每週/每單元）記錄進度與困難點。
- **可驗證：** 透過測驗與錯題回顧確認你真的掌握，而非只看完內容。

## 子頁面

- [影片學習區](./video-learning-zone.md)：透過影片課程快速理解重點。
- [學習測驗區](./learning-quiz-zone.md)：透過題目檢核學習成效。

## 學習地圖（建議）

| 階段    | 目標                   | 主要活動                   | 驗收方式                 |
| ------- | ---------------------- | -------------------------- | ------------------------ |
| 1. 導入 | 建立全貌與關鍵術語     | 觀看單元導覽影片、整理名詞 | 能用自己的話說明主題     |
| 2. 理解 | 掌握核心觀念與流程     | 觀看觀念拆解影片、做筆記   | 完成單元小練習           |
| 3. 應用 | 把觀念轉為可執行技能   | 跟做實作示範、獨立重做     | 產出可重現成果           |
| 4. 驗證 | 確認真正吸收與弱點位置 | 完成測驗、檢討錯題         | 錯題率下降與二次作答提升 |

## 建議學習流程

1. 先閱讀本中心內容與學習目標。
2. 前往 [影片學習區](./video-learning-zone.md) 完成影片課程。
3. 前往 [學習測驗區](./learning-quiz-zone.md) 完成測驗與自我評估。

## 每週學習節奏（範例）

- **週一：** 觀看導覽 + 觀念影片（30–60 分鐘）
- **週三：** 實作示範跟做 + 筆記整理（30–60 分鐘）
- **週五：** 完成測驗 + 錯題回顧（20–40 分鐘）
- **週末：** 針對弱點重看影片、做二次作答（20–40 分鐘）

## 學習紀錄建議欄位

你可以在個人筆記中固定記錄以下欄位：

1. **單元名稱**
2. **本次目標**
3. **已完成內容（影片/測驗）**
4. **卡住點與疑問**
5. **下一步行動（具體到可執行）**
