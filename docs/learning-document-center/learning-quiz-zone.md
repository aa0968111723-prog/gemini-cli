# 學習測驗區

本區提供測驗題目，協助你檢視學習成果並找出需加強的章節。

## 測驗類型

- 單選題
- 多選題
- 情境題

## 作答策略

1. **先做再查：** 第一次作答先不查資料，真實反映掌握程度。
2. **標記不確定題：** 即使答對，也要標記「不確定」以利後續複習。
3. **分類錯題原因：** 觀念不清、題意誤解、粗心失誤分開記錄。

## 建議作答流程

1. 先完成影片學習。
2. 限時作答並記錄不確定題目。
3. 回看影片或文件後再次練習。

> 建議每次完成測驗後，整理錯題筆記並持續追蹤進步情況。

## 錯題檢討模板（建議）

| 題號 | 我的答案 | 正確答案    | 錯誤原因     | 修正行動                |
| ---- | -------- | ----------- | ------------ | ----------------------- |
| Q1   | B        | D           | 名詞定義混淆 | 回看單元 1 觀念拆解影片 |
| Q2   | C        | C（不確定） | 猜對但不理解 | 補寫該概念的例子        |

## 成效判讀（參考）

- **80% 以上：** 可進入下一單元，並保留錯題做週回顧。
- **60%–79%：** 建議先補看對應影片，再做第二次測驗。
- **60% 以下：** 建議重跑該單元學習流程（導覽 → 拆解 → 實作 → 測驗）。
